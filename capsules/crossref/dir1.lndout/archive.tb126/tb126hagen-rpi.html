Title: TeX on the Raspberry Pi

Summary: report of TeX processing on all models of the RPi.

Full text of article: publicly available now.

Author: Hans Hagen

Publication: TUGboat volume 40, number 3 (2019), pages 232–233

DOI (this page): 10.47397/tb/40-3/tb126hagen-rpi
(previous doi - next doi)

Categories: Resources - Software & Tools

Difficulty: Intermediate

Abstract: This is a short status report on Pi, not the famous version number of TeX (among other things), but the small machine, meant for education but nowadays also used for Internet Of Things projects, process control and toy projects. While the majority of TeX installations run on an Intel processor, the Raspberry Pi has an ARM central processing unit. In fact, its main chip has the same foundation as those found in settop boxes all around the world. It’s made for entertainment, not for number crunching.
