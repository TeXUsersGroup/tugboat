Title: No more backtracking: Abbreviations in the Markdown package for TeX

Summary: marking up abbreviations for consistency.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Author: Vít Starý Novotný

Publication: TUGboat volume 47, number 2 (2026), pages 178–180

DOI (this page): 10.47397/tb/47-2/tb146starynovotny-markdown-abbrev
(previous doi - next doi)

Category: LaTeX

Difficulty: Intermediate Plus

Abstract: In traditional TeX workflows, marking up abbreviations is both tedious and fragile: once an abbreviation is introduced, authors must both revisit earlier text and remember to apply the same markup throughout the remainder of the document. In practice, this often leads to inconsistencies or omitted abbreviation markup.

This article presents new support for abbreviations in the Markdown package for TeX, shifting abbreviation handling from a procedural to a more declarative model. Editors can predefine standard abbreviations, while authors mark up individual occurrences as needed; the package then ensures that these abbreviations, whether introduced by editors or authors, are formatted consistently throughout the document.
