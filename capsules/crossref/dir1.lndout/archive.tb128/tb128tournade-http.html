Title: LaTeX-on-HTTP: LaTeX as a commodity web service for application developers

Summary: JSON-based HTTP API for running LaTeX over the web.

Full text of article: publicly available now.

Author: Yoan Tournade

Publication: TUGboat volume 41, number 2 (2020), pages 175–178

DOI (this page): 10.47397/tb/41-2/tb128tournade-http
(previous doi - next doi)

Category: Software & Tools

Difficulty: Advanced

Abstract: Although LaTeX is widely used in academia and education, only a few developers use it to create PDFs in web applications or IT systems. This seems strange considering that many developers are well exposed to these academic and scientific milieux—and that many recognize LaTeX for its superior typesetting qualities.

In this paper, we try to answer two questions:

  • Why use of LaTeX in IT systems is not widespread—and not even common?
  • How can we change this state of affairs?

In this article we give an overview of LaTeX-on-HTTP (github.com/YtoTech/latex-on-http), an attempt to commodify and simplify LaTeX use in web applications or IT systems, and to ease its adoption by modern developers.
