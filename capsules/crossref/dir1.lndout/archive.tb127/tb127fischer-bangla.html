Title: Typesetting Bangla script with LuaLaTeX

Summary: using HarfBuzz and luaotfload to achieve better shaping and colorization.

Full text of article: publicly available now.

Authors: Ulrike Fischer, Marcel Krüger

Publication: TUGboat volume 41, number 1 (2020), pages 69–70

Category: Multilingual Document Processing

Abstract: In [2], Md Qutub Uddin Sajib describes some experiences and insights concerning typesetting Bangla. While we don’t know Bangla, we want to share some additional information about the LuaLaTeX side, especially about how to use the possibilities of the new HarfBuzz library.
