Title: dtxmacrofont: Resizable macrocode in doc implementations

Summary: using different font sizes for \MacroFont and \AltMacroFont.

Full text of article: publicly available now.

Author: John E. Beach

Publication: TUGboat volume 46, number 1 (2025), pages 71–73

DOI (this page): 10.47397/tb/46-1/tb142beach-dtxmacrofont
(previous doi - next doi)

Category: LaTeX

Difficulty: Intermediate Plus

Abstract: macrocode environments in doc implementation text are typeset in the \small font size. The dtxmacrofont package allows the package author to select the font size through four declarations and reimplements \MacroFont and \AltMacroFont to typeset macrocode in the selected font size.
