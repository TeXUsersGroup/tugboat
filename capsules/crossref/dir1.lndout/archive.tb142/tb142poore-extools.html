Title: New tools for LaTeX package authors: Buffering, hashing, caching, serializing, and executing

Summary: new packages and features to help with verbatim processing, calling external programs, and more.

Full text of article: publicly available now.

Author: Geoffrey M. Poore

Publication: TUGboat volume 46, number 1 (2025), pages 60–68

DOI (this page): 10.47397/tb/46-1/tb142poore-extools
(previous doi - next doi)

Category: LaTeX

Difficulty: Advanced

Abstract: This paper provides an overview of new tools for LaTeX package authors that I created during the development of minted [7] version 3.

The fvextra [8] package can now save the contents of an environment verbatim in memory, in a form that allows line-by-line iteration. Then the saved contents or a modified version can later be typeset or written to an external file.

The new latex2pydata LaTeX package [9] allows key-value data to be written to a file in Python literal format [11]. Alternatively, data can be accumulated in an in-memory buffer which allows hashing or modification before optionally being written to a file. The new latex2pydata Python package [6] provides data loading and processing capabilities for data saved by the latex2pydata LaTeX package. Together, these packages make it possible to pass structured data from LaTeX into Python.

The new latexrestricted [5] Python package provides access to the file system and subprocesses in a manner consistent with LaTeX security settings. This simplifies the process of creating Python executables that meet the security requirements for LaTeX restricted shell escape.
