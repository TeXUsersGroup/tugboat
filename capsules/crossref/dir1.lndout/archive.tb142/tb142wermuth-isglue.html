Title: Is a given input a valid TeX ⟨glue⟩/⟨muglue⟩?

Summary: plain TeX conditional-like macro to test for a syntactic (mu)glue.

Full text of article: publicly available now.

Author: Udo Wermuth

Publication: TUGboat volume 46, number 1 (2025), pages 145–147

DOI (this page): 10.47397/tb/46-1/tb142wermuth-isglue
(previous doi - next doi)

Category: Macros

Difficulty: Advanced

Abstract: This article discusses the question of how one can determine if a given string of characters represents a valid glue or muglue value for TeX. A macro that looks and behaves like a Boolean conditional is implemented to answer the question.
