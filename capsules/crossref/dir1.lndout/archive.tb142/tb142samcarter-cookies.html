Title: Cookie cutters: An example workflow of how to generate simple 3D-printable objects from LaTeX graphics

Summary: step-by-step workflow to convert vector graphics into 3D models, using OpenSCAD.

Full text of article: publicly available now.

Authors: samcarter, Ulrike Fischer (orcid)

Abstract: This article will describe a step-by-step workflow for converting LaTeX vector graphics into simple 3D models. As a specific example, we will show how to create a 3D-printable model for a cookie cutter from a TikZ drawing using the open source program OpenSCAD.
