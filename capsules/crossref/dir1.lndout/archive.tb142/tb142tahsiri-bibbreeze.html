Title: BibBreeze: A LaTeX package to automate bibliography data

Summary: reconstructing references from inaccurate source files using expl3 and regular expressions.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Author: Amir Mohammad Tahsiri

Publication: TUGboat volume 46, number 1 (2025), pages 86–93

DOI (this page): 10.47397/tb/46-1/tb142tahsiri-bibbreeze
(previous doi - next doi)

Category: Bibliographies

Difficulty: Advanced

Abstract: The LaTeX package BibBreeze, written using LaTeX3, is a referencing package that automates bibliography reconstruction, eliminating manual effort in reference handling. It reorders disorganized fields for bibliography entries, fills in missing fields, and produces polished, reference style-compliant bibliographies optimized for researchers, academics, and writers. Currently, the package’s referencing style is designed for APA, both numeric and authoryear in-text citations, with more styles to come.

Using powerful packages such as expl3 and fundamental features such as regex, BibBreeze automatically extracts essential information from bibliography (BibTeX) entries and formats it according to the referencing guidelines. Furthermore, it distinguishes between entry subtypes such as proceedings papers (presented, published in journals or books) all identified by @inproceedings, using targeted checks. These features are especially valuable for users managing large reference lists who need precise formatting.
