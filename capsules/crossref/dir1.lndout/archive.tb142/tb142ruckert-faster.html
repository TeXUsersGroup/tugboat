Title: Efficient input file processing with TeX: A case study

Summary: profiling and reimplementing critical input parsing with a finite state machine.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Author: Martin Ruckert

Publication: TUGboat volume 46, number 1 (2025), pages 94–100

DOI (this page): 10.47397/tb/46-1/tb142ruckert-faster
(previous doi - next doi)

Category: Software & Tools

Difficulty: Advanced

Abstract: This paper illustrates the use of the TeX profiler for program analysis. Using as an example the index generation of the CWEB system for PDF documents, it shows how finite state machines can be implemented using TeX macros, and that input file processing using this technique is not only highly efficient but also leads to clean and compact code.
