Title: Styling Microsoft Power BI dashboards with TeX

Summary: using Python and Mathtext in Matplotlib to style business intelligence displays.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Author: Travis Stenborg

Publication: TUGboat volume 46, number 1 (2025), pages 156–157

DOI (this page): 10.47397/tb/46-1/tb142stenborg-powerbi
(previous doi - next doi)

Category: Graphics

Difficulty: Intermediate

Abstract: Microsoft Power BI dashboards can be styled with TeX. Such business intelligence dashboards can be displayed online via the Power BI Service, or offline in the Power BI Desktop application. This versatility can be implemented via Mathtext, a lightweight TeX parser embedded in Python’s Matplotlib library. Power BI’s TeX presentation capabilities are explored here with an example dashboard. Links to supporting file resources are supplied.
