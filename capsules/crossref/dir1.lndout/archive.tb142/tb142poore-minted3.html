Title: Typesetting code with syntax highlighting: Introducing minted version 3

Summary: improving security, usability, debugging, and enhancements via a dedicated latexminted executable.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Author: Geoffrey M. Poore

Publication: TUGboat volume 46, number 1 (2025), pages 54–59

DOI (this page): 10.47397/tb/46-1/tb142poore-minted3
(previous doi - next doi)

Category: LaTeX

Difficulty: Intermediate Plus

Abstract: The minted [5] package for LaTeX typesets code with syntax highlighting from the Pygments [1] library for Python. With version 3, minted enhances security and usability while adding new features and simplifying future development. The package includes a new Python executable called latexminted that is compatible with restricted shell escape. Usability is improved by new debugging and error reporting capabilities.

The redesign makes possible several additional features, including support for custom lexers and the ability to select snippets of code with regular expressions. The new architecture also allows future features to be developed using Python.
