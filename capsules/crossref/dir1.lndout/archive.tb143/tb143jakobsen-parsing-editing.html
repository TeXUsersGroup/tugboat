Title: Best-effort LaTeX parsing for interactive editing

Summary: supporting contextual autocomplete and a visual editor with a Lezer-built parser.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Author: Mathias Jakobsen (orcid)

Publication: TUGboat volume 46, number 2 (2025), pages 270–273

DOI (this page): 10.47397/tb/46-2/tb143jakobsen-parsing-editing
(previous doi - next doi)

Category: Software & Tools

Difficulty: Intermediate Plus

Abstract: Overleaf is a LaTeX editor with contextual assistance and interactive editing tools powered by a “best-effort” parsing engine. Rather than trying to fully understand all possible TeX documents, we focus on understanding conventional LaTeX structures where we can provide assistance to the user. This paper details the strategies behind this forgiving parser, and describes how we use the output of the parser to enable WYSIWYG editing features.
