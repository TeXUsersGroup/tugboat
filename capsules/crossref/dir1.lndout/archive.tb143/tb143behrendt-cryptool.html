Title: How we use LaTeX in the CrypTool project

Summary: math rendering in browsers in general, and using KaTeX in particular.

Full text of article: publicly available now.

Authors: Doris Behrendt, Bernd Busse

Publication: TUGboat volume 46, number 2 (2025), pages 206–212

DOI (this page): 10.47397/tb/46-2/tb143behrendt-cryptool
(previous doi - next doi)

Category: Electronic Documents

Difficulty: Advanced

Abstract: The CrypTool project with its long history uses LaTeX in two different scenarios: First, we use KaTeX for maths on our CrypTool online web page. Second, we used LuaLaTeX for building the recently re-edited CrypTool book (in German [3] and English [4]).

In this talk we limit ourselves to the topic of mathematical typesetting for interactive web applications in the browser with KaTeX.
