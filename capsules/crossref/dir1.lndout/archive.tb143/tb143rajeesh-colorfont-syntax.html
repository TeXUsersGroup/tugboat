Title: An OpenType font with built-in TeX syntax highlighting

Summary: COLRv1 and COLRv0 fonts for highlighting, usable in browers, LuaHBTeX, etc.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Authors: KV Rajeesh, CV Radhakrishnan (orcid)

Publication: TUGboat volume 46, number 2 (2025), pages 262–266

DOI (this page): 10.47397/tb/46-2/tb143rajeesh-colorfont-syntax
(previous doi - next doi)

Category: Fonts

Difficulty: Intermediate Plus

Abstract: In code editors, typesetting applications, and on the Web, syntax-highlighting is achieved via specialized ‘grammar’ files or JavaScript+CSS libraries. Using the colour table in OpenType fonts, we present development of a monospace font with basic built-in syntax highlighting for TeX and LaTeX documents.
