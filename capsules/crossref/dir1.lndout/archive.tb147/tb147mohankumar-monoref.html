Title: Single-pass cross-referencing in LuaLaTeX: Hold and patch

Summary: resolve forward and backward references within a single run.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Authors: Srikanth Mohankumar, Nareshkumar Krishnaswamy

Publication: TUGboat volume 47, number 3 (2026), pages 347–351

DOI (this page): 10.47397/tb/47-3/tb147mohankumar-monoref
(previous doi - next doi)

Category: LaTeX

Difficulty: Advanced

Abstract: The monoref package resolves a bounded set of LaTeX cross-references in one LuaLaTeX run: \ref, \pageref, plain numbered citations, a body-page total, and a generated table of contents. It does this by holding finished pages as Lua node lists, recording the true page of labels with invisible markers, and replacing reserved reference slots just before final shipout. This article describes the implementation and its trade-offs.
