Title: Do we need tagging?

Summary: testing whether LLMs suffice for reading PDFs with math.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Authors: Hans Hagen, Mikael P. Sundqvist

Publication: TUGboat volume 47, number 3 (2026), pages 324–327

DOI (this page): 10.47397/tb/47-3/tb147hagen-notagging
(previous doi - next doi)

Category: Accessibility

Difficulty: Intermediate

Abstract: Around 2026 tagged PDF was a bit of a hype and AI an even bigger one. But as with all ‘at some point fancy’ features and technology, one can’t predict if the hype is worth it. Just watch amazing tech from decades (or ages) ago that today is not around any more except in museums. With the two technologies above it might be that the first becomes obsolete when the second evolves more, and especially when these large language models become a useful and reliable tool. We therefore want to explore the following hypothesis:

Can we forget about (often unreliable) tagging and delegate accessibility to language models?

We will test this on some (simple) math and when we succeed we can assume (or hope) that for ordinary typeset documents the same applies. And therefore we can save us a lot of work, get less bloated files, where the bloat eventually gets ignored anyway.
