Title: Retrieving and typesetting Figshare metadata for LaTeX

Summary: LaTeX package for working with Figshare (figshare.com) metadata.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Author: Travis Stenborg (orcid)

Publication: TUGboat volume 47, number 3 (2026), pages 335–336

DOI (this page): 10.47397/tb/47-3/tb147stenborg-figshare
(previous doi - next doi)

Category: Electronic Documents

Difficulty: Intermediate

Abstract: Figshare publishes academic research data online. figshare-meta is a new LaTeX package for parsing and typesetting Figshare metadata. The Figshare API, JSON metadata and the jsonparse package were combined into a Figshare metadata workflow. This work was designed to support researchers, librarians, repository managers, or anyone else integrating Figshare metadata and LaTeX.
