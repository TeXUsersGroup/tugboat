Title: fddiagram: Typesetting functional dependency diagrams in LaTeX

Summary: declarative interface for creating the functional dependency diagrams in relational database research.

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Author: Rodrigo Smarzaro (orcid)

Publication: TUGboat volume 47, number 3 (2026), pages 377–379

DOI (this page): 10.47397/tb/47-3/tb147smarzaro-fddiagram
(previous doi - next doi)

Category: Graphics

Difficulty: Advanced

Abstract: The fddiagram package provides a declarative interface for typesetting functional dependency diagrams, a central concept in relational database theory and normalization, directly in LaTeX. The author writes dependencies in near-mathematical notation inside an environment; the package derives the attribute universe, computes all positions, and produces a TikZ-based diagram automatically. No TikZ knowledge is required. The package is implemented in LaTeX3 and is available at ctan.org/pkg/fddiagram and in TeX Live.
