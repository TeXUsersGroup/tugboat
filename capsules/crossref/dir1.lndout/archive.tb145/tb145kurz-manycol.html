Title: manycolposter: Minuscule minutes' text on DIN A0

Summary: printing large texts in a 2–6pt font size using 32 columns.
Erratum: on the printed contents by difficulty, the author was incorrectly attributed.

Full text of article: publicly available now.

Author: Stephan Kurz (orcid)

Publication: TUGboat volume 47, number 1 (2026), pages 48–51

DOI (this page): 10.47397/tb/47-1/tb145kurz-manycol
(previous doi - next doi)

Category: Humanities

Difficulty: Intermediate

Abstract: The challenge was to quickly typeset a whole book’s worth of content in a very small font on one large (DIN A0) sheet. For obvious legibility reasons, it had to be set a) in a typeface suitable for the task, and b) in many columns, preferably more than the 20 columns the multicol package currently provides. A usable result was obtained using the flowfram package.
