Title: ltx-talk: A class for accessible presentations

Full text of article: available to TUG members (join TUG); will be publicly available after the next issue is published.

Author: Joseph Wright

Publication: TUGboat volume 47, number 1 (2026), pages 64–66

(previous doi - next doi)

Category: LaTeX

Difficulty: Introductory

Abstract: Over the past 20 years, the beamer class [3] has become the standard for production of presentations with LaTeX. This class can produce a wide range of visual effects, and it has proved itself to be extremely useful for the creation of presentations. However, the internal code of beamer is very complex and somewhat idiosyncratic. The class focuses primarily on the visual output, with structures reused in a way that makes it difficult to see how tagging data can be added. Finally, some aspects of the user interface in beamer deviate significantly from standard LaTeX constructs and conventions.
