Title: Moloch: A minimalist, feature-rich Beamer theme

Summary: updating the Metropolis theme; generating PDF and HTML from a single source via Quarto.

Full text of article: publicly available now.

Authors: Johan Larsson (orcid), samcarter

Publication: TUGboat volume 47, number 1 (2026), pages 67–74

DOI (this page): 10.47397/tb/47-1/tb145larsson-moloch
(previous doi - next doi)

Category: LaTeX

Difficulty: Intermediate

Abstract: Moloch is a fork of the popular, but unmaintained, LaTeX Beamer theme Metropolis. It fixes outstanding issues in Metropolis while preserving the original minimalist design. In this article we introduce Moloch’s features and options, provide guidance for Metropolis users transitioning to Moloch, and describe the documentation system that we use to generate both PDF and HTML documentation.
