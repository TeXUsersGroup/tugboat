Title: A LaTeX package for the Aspen security protocol notation and BAN logic

Summary: an expressive and consistent notation for presenting security protocols.

Full text of article: publicly available now.

Author: Anders Andersen (orcid)

Publication: TUGboat volume 47, number 1 (2026), pages 75–80

DOI (this page): 10.47397/tb/47-1/tb145andersen-aspen
(previous doi - next doi)

Category: LaTeX

Difficulty: Intermediate Plus

Abstract: Aspen is a notation for security protocols. Despite the many publications and textbooks found using notations for security protocols, the notations used are not consistent. The motivation for Aspen is to have an expressive and consistent notation that can be used in different settings where security protocols are presented. The aspen package implements this notation for LaTeX. Optionally, the aspen package also provides the BAN logic notation.
