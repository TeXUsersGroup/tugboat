Title: Overview of TeX engines and formats

Summary: comparison of current engines (binary programs) and formats (TeX macro collections).
Addendum: The authors omitted the relatively new HiTeX engine created by Martin Ruckert, which generates HINT output for mobile devices; see HiTeX on CTAN for the code and documentation. It has been included in TeX Live for several years.

Full text of article: publicly available now.

Authors: Karl Berry (orcid), Max Chernoff, Jim Hefferon

Publication: TUGboat volume 46, number 3 (2025), pages 335–338

DOI (this page): 10.47397/tb/46-3/tb144berry-engines-formats
(previous doi - next doi)

Category: Surveys

Difficulty: Intermediate

Abstract: Among TeX and friends there are lots of moving parts. It can be hard to keep them straight. This brief article gives an overview of current major pieces of TeX software. Previous work goes into more detail [2,11].
