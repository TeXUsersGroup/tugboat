Title: Styling Maple graphics with TikZ and LaTeX

Summary: removing Maple's default styling and re-adding custom styling.

Full text of article: publicly available now.

Author: Travis Stenborg (orcid)

Publication: TUGboat volume 46, number 3 (2025), pages 379–380

DOI (this page): 10.47397/tb/46-3/tb144stenborg-maple
(previous doi - next doi)

Category: Graphics

Difficulty: Intermediate

Abstract: Styling Maple graphs with TikZ and LaTeX is demonstrated. This lets graphs escape Maple’s native formatting limits, and achieve visual harmony with LaTeX documents they’re embedded in. Supporting code resources have been made freely available.
