Title: BibTeX-based dataset generation for training citation parsers

Summary: improving citation structure recognition by training with large BibTeX databases.

Full text of article: publicly available now.

Authors: Sree Harsha Ramesh, Dung Thai, Boris Veytsman (orcid), Andrew McCallum

Publication: TUGboat volume 40, number 2 (2019), pages 167–169

DOI (this page): 10.47397/tb/40-2/tb125ramesh-cite
(previous doi - next doi)

Category: Bibliographies

Difficulty: Intermediate

Abstract: A citation graph is an important part of modern scientometrics (the field of analyzing and measuring of scientific literature). To construct it, we need to disambiguate citations: determine which paper cites which paper. While many publishers now deposit citation data in a machine readable format, some do not—and there are millions of older papers where only textual citation strings are available. Since manual conversion of these strings to parsed entries is not possible, we need to teach machines how to do this.
